# Documentation

This directory contains the static documentation and visual walkthroughs for the unified rowing pipeline.

## Published pages

- [GitHub Pages index](https://jjcappe.github.io/rowing-dynamics-analysis/)
- [Pipeline visualization](https://jjcappe.github.io/rowing-dynamics-analysis/pipeline-visualisation.html)
- [Model training stages](https://jjcappe.github.io/rowing-dynamics-analysis/model-training-stages.html)

## Local files

- `pipeline-visualisation.html`: end-to-end training and inference flow, including video/RP3 merge points, QC gates, model stages, and output artifacts.
- `model-training-stages.html`: Stage 0 / A / B model-training diagrams and evaluation protocol.
- `inference-cli-reference.md`: lower-level CLI flag reference for detection, matching, segment export, and dataset generation.
- `force-curve-inference-process.md`: biomechanics-first modeling notes and data-contract decisions.
- `journal/process-pics/`: image assets embedded by the docs pages and the root README.

## Current code architecture

The repo now uses `src/rowing/` as the package root, with `python -m rowing` as the primary Rich menu entry point. The old scripts under `scripts/` are compatibility shims that forward into the package modules.

Reports generated by the package live next to their artifacts:

- Per-run report: `<run>/inference/report/index.html`
- Per-training report: `<modeling_dir>/report/index.html`
