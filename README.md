# rowing-video-analysis

Video-first rowing biomechanics research pipeline.

The current working path is:

1. Extract pose and stroke signals from video (`sports2d_app/`).
2. Infer catch/finish drive events and optionally align to RP3 exports (`inference/`).
3. Build matched pose/force rows for force-curve modeling.

## Repository Modules

- `sports2d_app/`: main Sports2D + MotionBERT pipeline (Streamlit app and terminal wizard).
- `inference/`: drive-event detection, RP3 stroke matching, and matched segment export.
- `rp3-extraction/`: RP3 CSV cleanup/expansion utilities.
- `pose-extraction-test/`: annotation-first experimental pipeline kept for side-by-side testing.

## Environment Setup

From repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r sports2d_app/requirements.txt
```

## Typical Workflow

### 1) Run Sports2D pipeline

```bash
.venv/bin/python sports2d_app/app_cli.py
```

This creates a run folder under `runs/<video_stem>_<timestamp>/` with a dedicated `rp3/` subfolder.

### 2) Infer drive events from stroke signal

```bash
.venv/bin/python inference/inference_cli.py \
  --run-dir runs/<run_name> \
  --no-match-rp3 \
  --overlay-video
```

### 3) RP3 matching + force/pose segment export (auto clean)

Drop the dirty RP3 CSV for that run in `runs/<run_name>/rp3/`, then run:

```bash
.venv/bin/python inference/inference_cli.py \
  --run-dir runs/<run_name> \
  --anchor-rp3-stroke-number <stroke_number> \
  --active-side right
```

If multiple dirty RP3 files exist in `runs/<run_name>/rp3/`, also pass:
`--rp3-dirty-csv runs/<run_name>/rp3/<workout>.csv`.

## Key Run Artifacts

Within `runs/<run_name>/`:

- `stroke/stroke_signal.csv`: handle/machine stroke signal with catch/finish flags.
- `motionbert/angles_h36m.csv`: per-frame joint angles.
- `rp3/<workout>.csv`: dirty RP3 export for this run.
- `rp3/<workout>-clean.csv`: clean RP3 generated by inference.
- `inference/drive_events.csv`: per-stroke catch/finish timing inferred from stroke signal.
- `inference/rp3_match_manifest.csv`: video stroke to RP3 row mapping (if RP3 matching enabled).
- `inference/rp3_pose_force_matched_segments.csv`: canonical pose features aligned to RP3 force bins (`force_n` is PDF-normalized density; `force_raw` preserves original RP3 values).
- `inference/rp3_pose_force_export_status.csv`: one-row-per-matched-stroke export/drop status with explicit drop reasons.

## Notes

- If `--run-dir` or RP3 selection arguments are omitted in a TTY session, inference scripts can prompt interactively.
- Generated artifacts (videos, NPZ/CSV outputs) are intentionally not committed.
